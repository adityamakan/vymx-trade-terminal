# Dataset provenance

## `macro_yields_unverified_sample.csv`

This file is retained only as an unverified illustrative sample. It contains four quarterly rows and has no source URL, source retrieval timestamp, release vintage, revision history, or reproducible ingestion record in this repository.

**Do not use this file for macroeconomic analysis, trading decisions, backtests, charts presented as historical observations, or model training.** It is not loaded by the production application or the macro backtester.

Replace it only with a source-backed dataset that records the provider, series identifier, observation date, publication/retrieval timestamp, units, revision vintage, and any transformations. Official policy-rate, yield and inflation series must remain distinct from market proxies.
